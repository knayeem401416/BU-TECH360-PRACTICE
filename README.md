BU TECH 360

BU TECH 360 is a web-based Project Management System developed using PHP and MySQL. It manages student project submissions, mentor reviews, director approvals, notices, and academic information.

Features
👨‍🎓 Student Dashboard
Submit projects
Upload project PDF
View project status
View notices
👨‍🏫 Mentor Dashboard
Review projects
Download project PDFs
Pass projects to Director
Request recheck
👨‍💼 Director Dashboard
Review projects
Approve or reject projects
🧑‍💻 Officer Dashboard
Data entry
View academic information
Technologies
PHP
MySQL

CSS3
