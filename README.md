# BU TECH 360

BU TECH 360 is a web-based Project Management System developed using PHP and MySQL.

## Features

### Student
- Submit projects
- Upload project PDF
- View project status
- View notices

### Mentor
- Review projects
- Download project PDFs
- Pass projects to the Director
- Request project recheck

### Director
- Review projects
- Approve or reject projects

### Officer
- Enter academic data
- View academic information

## Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.2
- XAMPP
